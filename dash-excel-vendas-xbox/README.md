# 📊 Dashboard de Análise de Vendas — Excel

## 🧭 Visão Geral

Este projeto tem como objetivo **analisar o desempenho de vendas** de assinaturas de XBox ao longo do tempo, identificando padrões, tendências e oportunidades de melhoria.  
O dashboard foi desenvolvido em **Microsoft Excel**, utilizando **Tabelas Dinâmicas** e **segmentações de dados** para garantir uma análise dinâmica e intuitiva.

---

## 🎯 Objetivos do Projeto

- Identificar principais inddicadores de assinaturas e seus padrões
- Melhorar a visualização dos dados através de um dashboard e auxiliar na tomada de decisões
